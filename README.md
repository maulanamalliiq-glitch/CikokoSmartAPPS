# Cikoko SmartApp — Flutter Native

Repository untuk aplikasi Android **Cikoko**, package `com.KelurahanCikoko.malik`.

Sumber Flutter dan API cPanel sedang disiapkan sebagai paket ZIP terpisah. Jangan unggah keystore, private key Firebase, kredensial MySQL, atau data akun warga ke repo.

Pembangunan APK/AAB signed membutuhkan GitHub Actions Secrets dan pengujian di perangkat sebelum publikasi Play Store.
